⚙️ Regras dos presentes config/gifts.json

Como funciona

  • mode: "all" — todo presente vale: usa a regra dele ou default.
  • mode: "allowlist" — só os presentes da lista gifts valem; os demais seguem unlisted.
  • match — nomes (sem diferença de maiúsculas/acentos). ids — ids numéricos do TikTok.
  • team — "villain" (atrapalha) ou "hero" (ajuda).
  • effects — por unidade: bombs, food (comida dourada), grow (cresce na hora), attack (morde a cobra), shieldSec (escudo), clearBombs (limpa as bombas).
  • Itens especiais (também em effects, valor = quantos aparecem):
    😈 dano — bolt ⚡ raio (encolhe muito, some rápido), ice 🧊 gelo (deixa lenta), web 🕸️ teia (prende por alguns passos), skull ☠️ caveira (dano pesado);
    😇 bônus — diamond 💎 diamante (cresce +5), star ⭐ estrela (invencível), magnet 🧲 ímã (puxa as comidas), clock ⏱️ relógio (deixa rápida).
  • Efeitos por tempo, sem precisar do item: starSec, magnetSec, fastSec (segundos). E clearAll limpa bombas e itens.
  • combo — mesmas chaves de effects, para o espetáculo extra dos presentões (é aplicado junto).
  • Escala de recompensa: quanto mais caro o presente, mais coisa acontece — 1 moeda faz algo pequeno, o supremo dispara um combo (estrela + chuva de diamantes + limpar tudo).
  • Cada item tem limite no tabuleiro (⚡6, 🧊4, 🕸️4, ☠️3, 💎8, ⭐3, 🧲2, ⏱️3) e pavio próprio: o que passar disso é descartado.
  • tier — "normal", "mega" ou "supreme" (visual do card).
  • Sem regra: vira vilão pelo valor — bombsPerUnit + ⌊moedas / bombsPerCoins⌋ bombas.

Bomba mais forte

O dano da bomba agora é bombShrink + ⌊tamanho × bombShrinkPct⌋ (padrão da live: 4 + 20 %), e a cobra nasce com startLength (10). Assim a bomba dói de verdade numa cobra grande sem acabar a rodada em 3 segundos. Veja docs/DECISOES-LIVE.md para os números medidos.

Exemplo: só Rosa (vilã) e GG (herói)

{
  "mode": "allowlist",
  "unlisted": { "show": false, "countCoins": true },
  "fallback": { "team": "villain", "bombsPerUnit": 1,
                "bombsPerCoins": 10, "maxBombsPerEvent": 30 },
  "gifts": [
    { "name": "Rosa", "match": ["Rose", "Rosa"], "ids": [5655],
      "team": "villain", "effects": { "bombs": 1 }, "desc": "solta 1 bomba" },
    { "name": "GG", "match": ["GG"],
      "team": "hero", "effects": { "food": 1 }, "desc": "+1 comida dourada" },
    { "name": "Leão", "match": ["Lion", "Leão"], "tier": "supreme",
      "team": "villain", "effects": { "bombs": 40, "attack": 6 },
      "combo": { "bolt": 6, "ice": 4, "web": 4, "skull": 3 },
      "desc": "👑 40 bombas, mordida −6, ⚡ raios, 🧊 gelo, 🕸️ teias e ☠️ caveiras" }
  ]
}
